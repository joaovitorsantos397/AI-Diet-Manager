# Project FAQ

This document collects the main technical and product decisions behind the AI Diet Manager project.

Its purpose is to help explain the project clearly to others — recruiters, collaborators, or the author revisiting it later.

---

# Project Summary

AI Diet Manager is an AI-assisted nutrition application designed to help users improve their eating habits through personalized guidance.

The project is being developed as a Minimum Viable Product (MVP) with a strong focus on clean architecture, user experience and future scalability.

---

# Why did you build this project?

I wanted to build something that combines technology, Artificial Intelligence and health.

Instead of creating another CRUD application, I chose a project that solves a real-world problem while allowing future expansion.

---

# Why React?

The original idea was to develop the application using SwiftUI.

However, since development is currently being done on Windows, React became the most practical solution for building and validating the MVP.

The architecture was designed so that future migration remains possible if needed.

---

# Why AI?

Artificial Intelligence is the core of the product.

Rather than replacing nutrition professionals, the AI aims to provide personalized daily guidance and improve user engagement.

---

# How did you use AI during development?

AI was used as a development assistant.

It helped accelerate learning, generate implementation ideas and review architectural decisions.

However, every important decision was understood and documented before becoming part of the project.

---

# Biggest Challenge

One of the biggest challenges was balancing speed with understanding.

Instead of simply generating code, the goal was to understand the architecture and the reasoning behind every important decision.

---

# Product Thinking

Several product decisions were made before writing code.

Examples include:

- allowing users to choose their language;
- prioritizing simplicity over feature quantity;
- documenting architectural decisions from the beginning;
- designing for future scalability.

---

# What did you learn?

This project reinforced several software engineering concepts:

- component-based architecture;
- documentation;
- product thinking;
- incremental development;
- software organization;
- AI-assisted development.

---

# Future Improvements

Possible future improvements include:

- Apple Health integration;
- food recognition;
- personalized coaching;
- wearable integration;
- cloud synchronization;
- advanced analytics.

---

# Talking About This Project

When discussing the project:

- explain the reasoning behind decisions;
- demonstrate curiosity and willingness to learn;
- be honest about what was learned during development;
- emphasize product thinking rather than framework knowledge.
