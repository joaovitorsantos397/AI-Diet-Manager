# AI Diet Manager

## Project Context

### Purpose

AI Diet Manager is an AI-assisted nutrition application being developed as an MVP (Minimum Viable Product) and personal technical portfolio project.

The project has two equally important goals:

1. Build a functional and well-structured software product.
2. Demonstrate product thinking, engineering decisions, adaptability and learning ability.

---

# Current Development Stage

Current phase:

- React application successfully created.
- Running locally using Vite.
- Basic application architecture established.
- First welcome screen implemented.
- Language selection implemented using React state.
- UI refinement in progress.

---

# Development Philosophy

The objective is NOT to become a React expert in a few days.

Instead, development follows these principles:

- Learn only what is necessary.
- Prioritize delivering a polished MVP.
- Understand every important architectural decision.
- Keep the project organized from the beginning.
- Document important decisions.

# Documentation Structure

This repository intentionally contains documentation explaining not only HOW the software works but WHY decisions were made.

The documentation should help:

- future contributors
- future AI assistants
- recruiters and potential collaborators
- the author months later

---

# Development Method

Development is intentionally incremental.

Each step follows this sequence:

1. Understand the problem.
2. Explain the technology.
3. Implement only the necessary code.
4. Validate visually.
5. Document important decisions.
