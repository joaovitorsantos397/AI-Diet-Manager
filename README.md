# AI Diet Manager

An AI-powered nutrition assistant that helps users plan and monitor their diet.

## Project Overview

AI Diet Manager is a portfolio project designed to explore the use of artificial intelligence in nutrition planning.

The application collects basic user information, estimates daily calorie and macronutrient needs, and provides personalized meal suggestions through an AI assistant.

## Planned Features

- User profile with age, weight, height, sex, and fitness goal
- Basal metabolic rate and daily calorie estimation
- Macronutrient calculation
- Personalized meal suggestions
- Multilingual AI conversation
- Simple and intuitive interface

## Technologies

- Python
- Streamlit
- Git and GitHub
- AI API integration
